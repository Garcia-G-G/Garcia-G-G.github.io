What I actually do

  1. 01

    Create and harden the server

    Hetzner box created through the API on your account. Docker, a non-root deploy user, ufw limited to 22/80/443, fail2ban, unattended security upgrades, swap, sshd locked to keys only.

  2. 02

    DNS and TLS

    Cloudflare A record, SSL mode set to Full (strict) so you don't get the redirect loop, and Let's Encrypt issued correctly on the first try.

  3. 03

    Kamal 2, configured for a real app

    Your deploy.yml with Postgres and Redis as accessories bound to loopback, a worker role for Sidekiq or Solid Queue, volumes for Active Storage, asset_path so you don't get 404s mid-deploy, and a healthcheck that means something.

  4. 04

    Data moved, if there is any

    Database dumped from wherever it lives now and restored on the box, extensions checked, uploads moved onto the volume. Cut over with a low TTL so the rollback is one DNS change.

  5. 05

    Backups that leave the machine

    Nightly pg_dump pushed to any S3-compatible bucket, with retention. And one restore tested in front of you, because a backup you've never restored is a guess.

  6. 06

    A walkthrough, and then it's yours

    Half an hour on a call: how to deploy, how to roll back, how to read logs, how to open a console, what to do when it won't boot. Plus the troubleshooting doc for the 14 errors you'll eventually hit.

Who this is and isn't for

Worth it

  • You're paying Heroku or Render more than $50/month for something that fits on one box.
  • You have several small apps — the second and third cost almost nothing on the same server.
  • You've been meaning to move for months and it keeps losing to feature work.
  • You want to own the setup but not spend two evenings learning Kamal's sharp edges first.

Not worth it

  • You need real high availability. One box is one box, and rebuilding that on your own costs more than the platform you're leaving.
  • The app is pre-revenue and your time is better spent shipping than saving $1,200 a year.
  • You have no interest in servers at all and nobody to call. A managed platform is cheap insurance against your own 3am.

I'd rather tell you not to bother than take $150 for something you'll regret in a month.

Read access to the repo, a Hetzner API token, a Cloudflare API token scoped to the one zone, and a GitHub token for the container registry. All created by you, all revocable the moment we're done.

No. If you'd rather move the database yourself, I'll set everything else up and hand you the exact commands. Plenty of people prefer that.

Nothing, unless you want it. You deploy with one command and pay Hetzner directly. If you'd rather I stayed on for changes, we can agree that separately — but the $150 is not a hook for a subscription.
